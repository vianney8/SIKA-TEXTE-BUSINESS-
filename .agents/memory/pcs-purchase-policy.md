---
name: Optional additional PCS purchases
description: Buying another PCS code is optional once the user already owns at least one.
---

Once a user owns at least one PCS code, present the purchase action as “Payer un nouveau code PCS” and explain that buying another is optional. This is based on ownership, not activation status; the activation action is a separate flow.

**Why:** The user explicitly asked to make additional purchases clearly optional for users who already have a PCS code.

**How to apply:** Keep the existing initial-purchase label for users without a code, and retain the same purchase destination for additional purchases.
